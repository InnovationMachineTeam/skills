# Knowledge workspace

- `inbox/`: untrusted candidates awaiting curation;
- `concepts/`: verified atomic concepts and facts;
- `sources/`: source summaries with provenance and checked dates;
- `conflicts/`: explicit contradictions awaiting or recording resolution;
- `maps-of-content/`: progressive-disclosure indexes.

Create directories only when a real page needs them. Follow
[`docs/KNOWLEDGE-PLANE.md`](../KNOWLEDGE-PLANE.md). `README.md` files are not
graph nodes; curated pages require the complete frontmatter contract.
