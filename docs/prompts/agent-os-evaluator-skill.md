# Master Prompt For The `agent-os-evaluator` Skill

Apply after [agent-os-base.md](agent-os-base.md). Create an independent
assurance skill for Agentic OS architecture, implementation and release
evidence. It does not repair the candidate during a frozen run.

Evaluate plane boundaries, schema/API compatibility, registry reconciliation,
policy enforcement, durable execution, knowledge provenance, observability,
operator readiness and end-to-end outcomes. Combine deterministic conformance,
semantic task rubrics, repeated variance runs, chaos/failure injection,
security abuse cases, load/cost/latency tests and lifecycle migrations.

Freeze candidate, config, fixtures, model/tool versions and thresholds. Keep
holdouts from builders and reduce producer/evaluator correlated failure. Test
duplicate tasks, split brain, provider/store/network outage, stale policy,
credential revocation, tenant escape, poison memory, cancellation/rollback and
disaster recovery. Return per-layer `PASS`, `FAIL`, `INCONCLUSIVE` or `WAIVED`
with raw evidence, uncertainty, blockers and no implicit release approval.
