# Worked-Example Instructions

`CLAUDE.md` and `AGENTS.md` at this level are a synchronized pair. Any change to
this file must be applied to `AGENTS.md` in the same directory, and any change
to `AGENTS.md` must be applied to this file. Keep the two files byte-identical.

- Label examples as blueprints unless execution evidence exists.
- For every domain, decide one agent versus team versus Agentic OS explicitly.
- Include artifacts, roles, private/public skills, documents, permissions,
  model-policy properties, workflow, evaluation, approval, and rollback.
- Do not turn role lists into teams without boundary evidence.
- Keep external communication, spending, PII, production mutation, publication,
  and deployment behind explicit authority.
- Link new cross-domain findings to `../INSIGHTS-AGENT-SYSTEM-DESIGN.md`.
