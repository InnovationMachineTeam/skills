# Security and Authority Diagnostic Prompt

Apply after [base.md](base.md).

Contain unsafe behavior first. Map trusted instruction channels, capabilities, permissions, obligations, recipients, destinations, sensitive data, network egress, and consequential actions.

Test prompt injection in files, references, web content, fixtures, messages, and tool output. Inspect secrets, logs, global installation, destructive actions, unbounded retries, ambiguous external results, and missing verification.

Repair with least privilege, exact targets, consent, data minimization, idempotency, verification, and rollback. Prefer policies, schemas, hooks, allowlists, and sandboxes over text-only promises. Do not restore functionality by weakening controls.
