# Prompts and Templates Prompt

Extract reusable instruction overlays, intake questions, variable slots, output contracts, checklists, and artifact structures.

Preserve purpose, triggering context, required inputs, degrees of freedom, safety boundaries, failure handling, and completion criteria. Remove source-specific names only when the abstraction remains faithful. Do not copy long protected text; prefer a structural description and concise rights-cleared fragments.

Reject prompts that rely on hidden context, conflicting authority, unverifiable claims, or indiscriminate "do everything" behavior.
