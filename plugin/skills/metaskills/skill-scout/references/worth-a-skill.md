# Worth-a-Skill Gate

A strong opportunity has a recognizable user intent, recurring or high-leverage need, stable outcome, reusable procedure or knowledge, bounded authority, and meaningful evaluation.

Prefer alternatives when:

- a mature existing skill already fits;
- a deterministic script or automation is sufficient;
- the need is a one-off task or personal preference;
- the topic is too broad to trigger reliably;
- context or maintenance cost exceeds expected value;
- required authority is unsafe or unclear;
- correctness cannot be evaluated meaningfully.

Do not require frequent recurrence when a rare task is extremely consequential and a skill would materially reduce risk.
