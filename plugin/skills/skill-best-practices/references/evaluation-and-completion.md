# Evaluation and completion

## Source layer

- registry IDs and locators are unique;
- canonical sources are current or explicitly unavailable;
- repository revisions and licenses are recorded;
- summaries distinguish observed findings from inference;
- snapshot comparisons separate byte and semantic change.

## Synthesis layer

- every material practice cites registered sources;
- normative, platform, enterprise, and exemplar scopes remain distinct;
- contradictions have explicit resolutions or remain open;
- deprecated rules name their replacement or reason;
- unavailable evidence is not reported as unchanged.

## Corpus layer

- all required thematic files exist;
- practice IDs are unique;
- source IDs resolve;
- no broken relative links or duplicate canonical rules exist;
- INDEX records rebuild date, source snapshot, conflicts, and validation;
- staging differs from last-known-good only by explainable changes.

## Managed-skill layer

- every target is resolved before audit;
- applicability is evaluated per skill;
- changes preserve intended behavior and authority or explicitly approve differences;
- relevant official, routing, behavior, script, security, portability, catalog, consumer, E2E, and rollback checks pass;
- installation and activation are verified by the target host.

Do not call a refresh complete merely because pages were fetched, a rebuild complete because files were written, or a portfolio update complete because a master prompt was generated.
