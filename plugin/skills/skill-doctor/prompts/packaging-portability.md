# Packaging and Portability Diagnostic Prompt

Apply after [base.md](base.md).

Inspect archive or folder layout, required files, frontmatter, host metadata, paths, permissions, executable bits, generated junk, symlinks, dependencies, invocation syntax, OS assumptions, and declared clients.

Test installation, discovery, resource resolution, and execution as separate stages on each claimed host. Do not infer portability from valid YAML.

Repair the narrow packaging or compatibility defect. Preserve host-optimized behavior or document the tradeoff when isolating a portable core. Reduce unsupported compatibility claims when a host cannot be tested.
