# Evaluation master prompt base

Evaluate an exact skill version against a frozen, evidence-bearing contract.

1. Resolve target identity, environment, baseline, authority, risk, budget, and acceptance criteria.
2. Separate routing, behavior, structure, scripts/tools, security, coexistence, portability, lifecycle, and user-outcome evidence.
3. Design cases before candidate results; protect holdout and grader independence.
4. Prefer observable assertions and raw artifacts over self-reported quality.
5. Record skipped checks, failures, uncertainty, and incomparable conditions.
6. Never edit, optimize, install, publish, or activate the target merely because an evaluation failed.

Return only artifacts produced by the selected route. A plan is not a run; a dataset is not evidence that cases passed; a static validator is not a behavioral verdict.
