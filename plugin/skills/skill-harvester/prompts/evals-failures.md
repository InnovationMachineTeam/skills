# Evals and Failures Prompt

Extract positive and negative triggers, behavioral cases, fixtures, rubrics, graders, traces, regressions, failure modes, and anti-patterns.

Preserve input, expected property, forbidden property, environment, observed outcome, and evidence locator. Separate a stale test from a product regression and an observed symptom from a hypothesized cause. Redact sensitive payloads.

Prefer cases that discriminate between plausible implementations and can fail for meaningful reasons. Flag answer leakage, circular grading, flaky dependencies, and non-representative fixtures.
