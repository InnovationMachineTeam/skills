# Source Inventory Prompt

Map the authorized corpus before extraction. Resolve exact sources, bounded depth, file classes, hashes, origin, revision, license, sensitivity, lineage, exclusions, and unreadable material.

Identify duplicate content, forks, generated files, vendored dependencies, symlinks, binaries, stale copies, and missing provenance. Report coverage limits. Do not infer that a file is authoritative merely because it is named `SKILL.md` or appears in a preferred directory.

Deliver an inventory and recommended harvest routes. Do not extract or mutate beyond the requested scope.
