# Route: catalog-curation

Curate the catalog without changing skill identity accidentally.

For every candidate skill:

1. Verify directory/name match and provenance.
2. Detect duplicates by name, behavior, and install namespace.
3. Select one primary category and optional tags.
4. Preserve a stable name during category movement unless identity changes.
5. Confirm self-containment after the target move.
6. Record version and release implications.

For removal or deprecation, produce impact and rollback before mutation. Do not delete or retire by implication.
