# Compatibility and Migration

Inventory direct invocation names, implicit routing phrases, links, scripts, plugins, automations, dependent skills, documentation, and users. A folder rename can break more than file references.

Use staged candidates, compatibility facades, explicit aliases where supported, consumer migration, canary rollout, and last-known-good recovery. Do not infer active host behavior from filesystem layout. Route installation, precedence, disablement, and retirement to `skill-manager`.
