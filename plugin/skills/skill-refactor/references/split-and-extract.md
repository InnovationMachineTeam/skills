# Split and Extract

Use `SPLIT` or `EXTRACT_SUBSKILL` when a component has an independent trigger, output, authority, resources, and falsifiable completion test. Use `EXTRACT_REFERENCE` when only conditional knowledge or examples should leave SKILL.md.

Avoid fragments that require hidden parent context, share mutable state without an owner, or cannot be invoked and evaluated independently. Assign every original trigger, resource, consumer, and regression case to a destination or explicit retirement decision.
