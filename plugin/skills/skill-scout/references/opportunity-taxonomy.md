# Opportunity Taxonomy

- **Knowledge gap**: specialized stable knowledge is repeatedly rediscovered.
- **Workflow gap**: a multi-step procedure, gate, or recovery path recurs.
- **Tool gap**: fragile tool use or integration needs reusable guidance or scripts.
- **Artifact gap**: a recurring deliverable has stable structure and quality criteria.
- **Evaluation gap**: repeated judgment needs rubrics, fixtures, or graders.
- **Safety gap**: recurring authority, privacy, recovery, or injection failures need guardrails.
- **Routing gap**: intent repeatedly selects the wrong capability or requires the same clarification.
- **Portfolio gap**: existing skills cover adjacent work but leave a coherent missing capability.

Do not confuse a topic, one-off request, product feature, automation, memory item, or preference with a skill opportunity.
