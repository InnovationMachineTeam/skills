# Workflow, State, and Recovery Diagnostic Prompt

Apply after [base.md](base.md).

Trace entry conditions, stages, branches, clarification, checkpoints, retries, partial success, resume, verification, and completion. Identify the first divergence between expected and observed state.

Check conflicting absolutes, skipped prerequisites, stale checkpoints, non-idempotent retry, false completion, premature blocker reports, and lost state after interruption.

Repair the smallest state transition or condition. Preserve valid flexibility. Test normal, optional, interrupted, resumed, transient-failure, permanent-failure, partial-success, and rejected-confirmation paths as relevant.
