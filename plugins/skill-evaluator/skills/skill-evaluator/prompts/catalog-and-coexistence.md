# Route: catalog-and-coexistence

Evaluate the skill among realistic neighbors and common compositions.

1. Resolve actual catalog metadata, truncation/budget behavior, precedence, and resolver state.
2. Include nearest semantic neighbors, built-in collisions, explicit invocation, ambiguous requests, and multi-skill compositions.
3. Test isolation and coexistence, not only the target in an empty catalog.
4. Measure false capture, missed routing, catalog recall, ambiguity, context cost, and downstream composition failures.
5. Preserve platform-specific findings rather than claiming portable behavior.

Do not rename, disable, or reorder installed skills during a read-only evaluation.
