# Patterns and Workflows Prompt

Extract trigger rules, sequences, decisions, states, gates, fallback paths, clarification strategies, verification loops, and recovery procedures.

For each pattern, separate invariant intent from host-specific implementation. Record inputs, preconditions, ordered steps, side effects, outputs, failure modes, authority boundaries, and a falsifiable check. Treat repeated wording from common ancestry as one lineage.

Preserve incompatible variants instead of merging them into a vague compromise.
