# Standard model profile

Use for a model with comparable evidence of reliable planning, tool use, state
tracking and self-correction.

1. Follow the current factory phase and its exit checks.
2. Choose implementation details using project conventions and surrounding
   interfaces unless an invariant requires a specific choice.
3. Summarize assumptions and decisions; avoid restating loaded contracts.
4. Validate the produced artifact and update state before advancing.
5. Escalate only material ambiguity, authority gaps or blocking evidence.

Do not preload later phases or private subskills.
