# Agentic OS Skill Instructions

`CLAUDE.md` and `AGENTS.md` at this level are a synchronized pair. Any change to
this file must be applied to `AGENTS.md` in the same directory, and any change
to `AGENTS.md` must be applied to this file. Keep the two files byte-identical.

- Require evidence that an ordinary agent-team runtime is insufficient.
- Compare build, extend, buy, and no-platform options before architecture.
- Start with one approved, non-production, end-to-end vertical slice.
- Separate experience, control, execution, knowledge, assurance, and operations
  planes and their owners.
- Enforce policy outside prompts; distinguish desired registry state from
  observed runtime state.
- Pin versions and use durable tasks, leases, fencing, budgets, cancellation,
  checkpoints, compensation, recovery, and terminal states.
- Bootstrap, evaluation, registration, activation, rollout, and production
  deployment are separate decisions.
