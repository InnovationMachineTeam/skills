# Agentic OS evaluation contract

Required layers: architecture, schema/API compatibility, registry, policy,
runtime, knowledge, observability, operator readiness, security, lifecycle and
end-to-end outcome. Every layer records verdict, blocking flag, evidence refs,
environment and uncertainty.

Waivers name scope, reason, approver, expiry and residual risk. `PASS` requires
all blocking layers pass; waived blockers produce at most a conditional release
recommendation. The evaluator never mutates the candidate or approval state.
