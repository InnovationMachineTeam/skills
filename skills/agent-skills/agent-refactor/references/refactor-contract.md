# Agent refactor contract

Record current topology and consumers before proposing change. Compare mission
cohesion, triggers, permissions, context, state, models, verification,
documentation ownership, runtime coupling and lifecycle cost.

Every migration has old/new identities and versions, compatibility, ordered
consumer moves, registry/map transaction, state/memory/doc migration,
coexistence, evaluation, rollback and retirement criteria. Private capability
promotion requires independent consumers, generalized contract, independent
owner/lifecycle and global routing tests.

A folder move without updated consumers, indexes, bindings, host discovery and
rollback is incomplete.
