# Agent-Team Skill Instructions

`CLAUDE.md` and `AGENTS.md` at this level are a synchronized pair. Any change to
this file must be applied to `AGENTS.md` in the same directory, and any change
to `AGENTS.md` must be applied to this file. Keep the two files byte-identical.

- Require evidence that one agent is insufficient before designing a team.
- Derive roles from context, authority, expertise, model, write-set, state, and
  independent-verification boundaries—not organization-chart labels.
- Keep architecture, model selection, build, skill mapping, orchestration,
  workspace management, and lifecycle management in their owning skills.
- Build only an approved exact specification and stage before promotion.
- Treat worktrees as write-set isolation, not a security boundary.
- Create and register required owner-private/public skills with the team.
- Keep activation, external communication, publication, spend, and deployment
  behind explicit human or policy approval.
