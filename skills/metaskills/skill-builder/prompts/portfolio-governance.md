# Scenario: portfolio-governance

Use for inventory, versions, conflicts, supply chain, rollout, policy, enablement, quarantine, or retirement across explicitly scoped skill roots.

1. Invoke `skill-manager` in Inventory or Plan mode first.
2. Verify identity, provenance, versions, host state, dependencies, conflicts, ownership, and rollback rather than inferring from folder presence.
3. Dispatch bounded findings: capability gaps to scout, evidence mining to harvester, new capabilities to `skill-architect`, missing or stale evaluation evidence to evaluator, unhealthy skills to doctor, healthy tuning to optimizer, topology changes to refactor.
4. Return specialist artifacts to manager for a single lifecycle manifest.
5. Obtain exact authorization before applying install, update, enable, disable, quarantine, migration, or retirement operations.
6. Require evaluator release evidence for changed high-risk skills, then regenerate inventory and verify actual host discovery, routing, consumers, versions, and rollback.

Do not let the builder or a specialist claim lifecycle state from filesystem changes alone.
