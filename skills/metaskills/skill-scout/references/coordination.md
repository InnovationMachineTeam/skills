# Coordination

Pass downstream only the minimum candidate-local context and link to raw evidence. Preserve user approval, rights, privacy, host, tools, permissions, output contract, tests, and forbidden side effects.

Require returned artifacts to cite candidate IDs. A downstream specialist may reject or reclassify a candidate when implementation evidence contradicts the scout hypothesis.

Use `skill-builder` as the handoff target when the user authorizes a multi-stage path from an approved opportunity through research, creation, validation, and optional activation. Keep a direct specialist handoff for a single bounded next step.
