# Existing Coverage

Search in this order:

1. explicitly supplied or installed local skill inventory;
2. organization-approved registry or repository;
3. reputable public skill catalogs and primary repositories;
4. broader web discovery when authorized.

Verify content rather than names. Compare triggers, negative triggers, outputs, authority, workflow, resources, dependencies, portability, tests, provenance, revision, license, security, adoption, and maintenance.

Use coverage labels: `exact`, `extendable`, `composable`, `adjacent`, `none`, or `unknown`. Search failure means `unknown`, not `none`.
