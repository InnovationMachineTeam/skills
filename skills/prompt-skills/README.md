# Prompt Skills

Prompt skills design, audit, and optimize durable controlling prompts. “Master
prompt” is an internal design term; public skill and command names use `prompt`.

Use `prompt-optimize` for prompt structure, authority boundaries, context,
outputs, failure handling, evaluation hooks, and bounded iteration. Do not use a
prompt to grant permissions, replace external policy enforcement, or hide a
workflow that should be a skill, agent, team, or Agentic OS component.
