# Constrained construction profile

1. Create a checklist for goal, inputs, authority, prohibited effects, output
   schema, failure behavior and Definition of Done.
2. Label every source statement as instruction, observation, inference,
   assumption or recommendation before drafting.
3. Execute one package-workflow stage at a time and validate its required
   fields before advancing.
4. Resolve conflicts by instruction priority and preserved authority; never
   silently average incompatible rules.
5. Build the smallest selected depth from an explicit template.
6. Run the declared checks. Correct one failed draft, then return the failed
   assertion and required human decision if it still fails.

Do not invent missing facts or claim improvement from shorter text alone.
